# 手机远控故障隔离与恢复接入说明

日期：2026-09-17。状态：已实现并通过定向验证，待部署/真实环境联调。适用：LobsterAI、lobsterai-server。配套服务端 Spec：`docs/specs/mobile-remote-control/feature-2026-09-17-remote-resilience.md`。

## 1. 变更摘要

服务端修复清理类别相互阻塞、产物事务加锁顺序、v1 产物事件保留窗口、文件账本核对效率。桌面端补充遗留运行与模型配置的本地 Gateway 核对，回收已过期且从未绑定命令的附件缓存。远控上传失败、WS 断开、服务端重启不应成为普通本地任务执行的前置条件。

## 2. 接口与认证

本次不新增或删除 HTTP 接口，不改变 `/api/remote/v1/*` 路径、请求必填字段、响应信封、错误码、鉴权头或 WS 消息契约；原请求/响应示例继续有效。沿用原 Bearer token、设备凭证、账号/空间归属与会话权限校验，不要求 App 为本次修复升级。

新增的 `querySessionRecovery` / `restoreSessionObservation` 是桌面进程内部运行适配接口，不是服务端公开接口，也不通过手机调用。读取现有本地 Gateway `sessions.list`、`agent.wait`，不会重新发送原任务或模型变更。

## 3. 桌面端行动项

- 升级桌面执行适配层和 SessionCommandService。只有存在 inputFence 或 reconciling 的目标会话才查询恢复证据；普通新建/继续不等待远控连接成功。
- 历史页面触发后台核对，显示历史无需等待核对。提交前同一会话核对合并且有超时；返回后重验账号代次、运行身份及隔离标记，避免切号或旧响应覆盖当前会话。
- 未知模型变更即使读回目标值也不证明原写操作已结束。须持久化的原写者 PID 确认退出且新 Gateway 返回实际值、没有活动任务时才按实际配置恢复；已有引擎重启入口可终止受管理的原写者，但不自动重启以免影响其他任务。旧 fence 没有原 PID 时保留隔离并提示新建任务，不以首次补记当前 PID 伪造证明。未知运行不得从空列表推断终态。
- 恢复不能确认时只保护受影响会话，提示重试/重启引擎或新建任务；不可绕过账号隔离、审批或并发执行检查。
- 未发送附件在过期 24 小时后按受控目录分页清理；先持久化删除标记，绑定阶段重读，删除失败重试。已绑定文件不由此规则清理。

## 4. 发布与配置

本次无新增服务端 DDL，已有版本要求的 V88–V97 仍为前置条件。服务端可先发布；旧客户端协议继续兼容，桌面可独立发布本地恢复修复。已有 sync_retention_v2 的混部/回滚限制仍按原接入文档执行，本次不放宽协议 fence。

功能开关默认开启。账本核对新增四个默认参数，可保留现有启动命令：

| 参数 | 默认 |
| --- | --- |
| remote-control.files.quota-reconcile-ms | 60000 毫秒 |
| remote-control.files.quota-reconcile-batch-size | 100 个候选账号 |
| remote-control.files.quota-reconcile-budget-ms | 1000 毫秒；只限制是否开始下一个账号 |
| remote-control.files.quota-recheck-hours | 1 小时 |

真实存储证明、引用和账本一致性仍是删除前置条件。单类清理调度失败通过 `remote.gc.<kind>.scheduled.error` Metriclog 记录次数及耗时，后续类别继续尝试。

## 5. 验证与限制

离线回归覆盖服务端清理租约/节流、锁顺序、保留窗口与账本；桌面覆盖恢复证据、账号切换、未知结果、无远控连接的本地操作及附件清理。最终执行结果见配套 Spec。真实 App 展示、MySQL 并发锁、四节点滚动和 NOS 删除闭环仍需环境验收。本次不执行部署、共享数据库清理或真实用户文件删除。

验证结果：服务端 57 套/537 项测试与 bootJar 通过；桌面 28 文件/631 项定向测试、Electron 编译及改动文件 ESLint 通过。本轮没有执行数据库迁移或部署。
